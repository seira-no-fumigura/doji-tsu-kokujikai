# 童子通（どうじつう）

星羅の文庫（せいらのふみぐら）の一作品です。著作権の保護期間が満了した本から起こした本文を、誰でも読み・使い・直せるように置いています。

童子通。山本蕉逸の著で、句読・音訓・反切・四声・似た文字の区別・読むべき書籍の次第・和漢歴史の大要・作詩作文など、漢文を学ぶ童子のための手引き。明治 44 年（1911 年）に早稲田大学出版部が『漢籍国字解全書』第 7 巻に、小学示蒙句解の附として収めたもの。OCR の柱から付けた見出しが付く。

## 底本

- [漢籍国字解全書 : 先哲遺著](https://dl.ndl.go.jp/pid/898780)（早稲田大学編輯部 編・早稲田大学出版部・1911年）。国立国会図書館の全文テキスト（OCR）のまま

国立国会図書館デジタルコレクション（インターネット公開）の全文テキスト（OCR）をそのまま収めた。1 段落が底本の 1 コマ（見開き）。校正はしていないので、振り仮名や柱の混じり、読み違いが残る。
